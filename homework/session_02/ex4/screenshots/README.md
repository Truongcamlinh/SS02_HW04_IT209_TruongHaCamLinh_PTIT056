# Ảnh minh chứng cần bổ sung từ DigitalOcean

Sau khi tạo Cloud Firewall, chụp màn hình DigitalOcean Console và lưu tại:

```text
digitalocean-cloud-firewall.png
```

Ảnh cần hiển thị:

- Inbound SSH, TCP 22.
- Inbound HTTP, TCP 80.
- Droplet đã được gán vào firewall.

Ảnh phải lấy từ tài khoản DigitalOcean và Droplet thật; không dùng ảnh minh họa.
